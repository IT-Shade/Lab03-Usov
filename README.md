ПР3. Ответы на контрольные вопросы.
1. Разницы нет. Это не новая операция, а просто более короткая запись.
2. Разница есть. В x++ сначала идёт возврат старого значения, а потом увеличение. В ++x наоборот, сначала увеличение, а потом возврат старого значения.
3. В результате сравнения оператора всегда используется true или false.
4. Короткое замыкание в && и || - это конфликт между знаками, то есть нужен какой-то один, а другой нужно убрать.
